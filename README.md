# retail-sales-powerbi-dashboard
Retail sales analysis and interactive dashboard built using Power BI
Retail Sales Analysis Dashboard — Power BI

Project Overview

This project analyzes retail sales data using Microsoft Power BI. The dashboard summarizes sales performance and presents key business metrics through interactive visualizations.

Tools Used

- Microsoft Power BI Desktop
- Microsoft Excel

Dashboard Features

- Total sales
- Total orders
- Average order value
- Sales by city
- Sales by product
- Sales by month
- Sales by salesperson

Key Objectives

- Compare sales performance across cities.
- Identify top-performing products.
- Present business metrics in a clear visual dashboard.

Files Included

- "Retail_Sales_Analysis.pbix" — Power BI dashboard file
- "Retail Sales Dataset.xlsx" — Source dataset

How to Use

Download the ".pbix" file and open it using Power BI Desktop to explore the report.

Disclaimer

This is a learning project using sample retail sales data.
